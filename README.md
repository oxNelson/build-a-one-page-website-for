## ✦ Architecture & Highlights

- **Aesthetic Direction**: Neo-brutalist elegance meets Swiss editorial typography (`Syne`, `Plus Jakarta Sans`, and `JetBrains Mono`).
- **Interactive Ambient Canvas**: Generative fluid glowing gradient physics rendered via 2D Canvas and real-time mouse interaction at 60 FPS.
- **Dual Visual Themes**: Instant toggle between **Dark Obsidian** and **Editorial Light** modes with `localStorage` memory and OS preference detection.
- **Micro-Haptics & Audio Synthesizer**: Built-in sound effects engine synthesized via the browser's native Web Audio API (zero audio downloads needed).
- **Interactive Scope & Investment Estimator**: Dynamic real-time project calculator with instant transfer to the Project Brief form.
- **Editorial Case Study Modal**: Deep dive into real-world client case studies with challenges, solutions, metrics, and galleries.
- **Live World Clocks**: Synchronized real-time hub clocks for New York, London, Zurich, and Tokyo.
- **Methodology & Capabilities Accordions**: Clear, transparent breakdowns of client engagements and deliverables.
- **Zero Framework Bloat**: Pure HTML5, modern CSS custom properties, and modular Vanilla JavaScript.
